# Kandela

**English** · [Português](README.pt-BR.md)

A local, minimal distraction dimmer for the Mac (a free alternative to
[HazeOver](https://hazeover.com)): it dims every window except the one in
focus. Plain Swift/AppKit, ~250 lines, no dependencies, no special permissions
(it asks for neither Accessibility nor Screen Recording).

Part of Kogumelo's family of tools, each with its own name starting with K
(see also [Konfig](https://github.com/Kogumelo/konfig)). It was called
`km-dimmer` until 2026-10-11.

## How it works

One translucent black window per display is always kept **right below** the
focused window in macOS's global window stack (window numbers are global, so
it can be ordered relative to other apps' windows). Clicks pass through the
overlay, and it is left out of screenshots.

## Build and run

Needs Swift from the Xcode Command Line Tools (`xcode-select --install`) and
macOS 11 or later.

```sh
./build.sh
open Kandela.app
```

Kandela's K shows up in the menu bar with (names follow the system language;
in English):

- **Enabled** — turns dimming on/off
- **Intensity** — 20% to 80%
- **Highlight All App Windows** — instead of just the front window, every
  window of the focused app stays lit
- **Quit Kandela**

Preferences are stored in `defaults` (`br.com.kogut.kandela`). On first
launch, Kandela copies the ones `km-dimmer` had stored in
`br.com.kogut.km-dimmer`.

## Icon

The mark (a K: the stem is a dimmed background window with the three macOS
traffic-light dots, and the lit arms are cut out on top of it) lives in
`Assets/kandela-mark.svg`. The menu bar icon is drawn in code
(`kandelaMark(size:)` in `Sources/main.swift`); the app icon is
`Resources/AppIcon.icns`, generated by:

```sh
swift Tools/make-icon.swift
```

The full-color app icon is also available as SVG, in `Assets/kandela.svg`
(to use as the project logo elsewhere).

All versions share the same geometry: change one, change the others.

## Translations

Code is in English. Menu titles use their own English text as the key, and
each language has its translation in
`Resources/<language>.lproj/Localizable.strings` (currently `en` and `pt-BR`).
To add a language, copy `Resources/en.lproj` to `Resources/<code>.lproj` and
translate the right-hand side of each line. `./build.sh` refuses to build if
any key used in the code is missing from any language.

## Launch at login

System Settings → General → Login Items & Extensions → "+" → Kandela.app

## Known limitations (vs. the paid HazeOver)

- Switching the dimming between windows is instant (no gradual fade between
  windows — fading only happens when turning on/off or changing intensity).
- No independent intensity per display.
- Focus changes within the same app are detected by polling (0.2 s), not by
  events — unnoticeable in practice, ~0% CPU.
